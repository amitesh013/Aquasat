# CSV inventory

This is the inventory of CSV files as supplied in the original ZIP. The active `dashboard_data.csv` and `metrics.csv` have since been rebuilt from the threshold-selected clear95 prior-only candidate. The immediately preceding files are preserved as `dashboard_data_pre_threshold_selected_20261019.csv` and `metrics_pre_threshold_selected_20261019.csv`; the earlier pre-clear95 backups remain as well. Counts and schemas below describe the archive snapshot, not those later replacements. The ZIP did not include a separate raw/clean manually transcribed file, requirements file, notebooks, or existing tests. Date ranges are shown only for columns recognized as date fields; `image_ymd` is a compact date key.

**Current forecast output update (19 October 2026):** `reservoir_forecasts.csv` was regenerated by `generate_live_xgboost_forecast.py`. ## Duplicate check
No byte-identical CSV duplicates were found in the supplied archive.

CSV dtype annotations are inferred from non-empty values and are descriptive, not declarations of a validated schema. The app directly loads `dashboard_data.csv`, `reservoir_forecasts.csv`, and `metrics.csv`; `prepare_data.py` regenerates the first two dashboard artifacts and metrics. `calibrate_all.py` expects `handwritten_ground_truth_clean.csv`, which is absent from the ZIP, so that script currently cannot run as supplied.
